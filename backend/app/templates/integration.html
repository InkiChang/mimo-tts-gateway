Important Notes

  • Replace YOUR_TOKEN with your actual gateway token from .env
  • The reading app must URL-encode {{ '{{' }}speakText{{ '}}' }} properly
  • Never put your upstream API key in the reading app URL
  • For Legado (阅读): Use double curly braces {{\{\{}speakText{{\}\}}}. The app auto-encodes the text.
  • If accessing from outside, use Tailscale / WireGuard / Cloudflare Tunnel
  • Do not expose port 8000 directly to the public internet
